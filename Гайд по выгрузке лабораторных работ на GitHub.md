# Пояснения

Всё, что пишется в знаках "<>", например, `<your_email>`, обозначает то, что вместо этого обозначения надо подставить какие-то свои данные. В случае приведённого примера `<your_email>` превращается в электронный адрес твоей почты.

Переходим по [ссылке](https://github.com/git-for-windows/git/releases/download/v2.54.0.windows.1/Git-2.54.0-64-bit.exe) , где у нас начинается загрузка установочного файла Git. Дальше идёт по номерам страничек установки:

4. 4 страница (поле с выбором editor) -- выбираем "Use Visual Studio Code as Git's default editor" и жмём "далее";
5. 5 страница (выбор названия default ветки) -- выбираем "Override default branch name for new repositories", там должно быть написано ниже в поле ввода "main", и жмём "далее";
6. 6 страница (Пункты с выбором) -- выбираем второй пункт "Git from the command line and also 3-rd-party software" и жмём "далее";
7. 7 страница (пункты с выбором) -- оставляем всё, как есть, и жмём "далее";
8. 8 страница (пункты с выбором) -- оставляем всё, как есть, и жмём "далее";
9. 9 страница (пункты с выбором) -- оставляем всё, как есть, и жмём "далее";
10. 10 страница (пункты с выбором) -- оставляем всё, как есть, и жмём "далее";
11. 11 страница (пункты с выбором) -- оставляем всё, как есть, и жмём "далее";

## Первичная настройка для того, чтобы работать с репозиториями в операционной системе

### Оформление "профиля" GitHub в ОС

Перед тем, как мы сможем всё сгружать и выгружать, нам надо сделать пару простеньких шагов:

1. Вводим в строке поиска программ "Git Bash" и открываем её.
2. Вводим команду `git config --global user.name "<your_name>"`, где вместо <your_name> пишем какой-угодно ник.
3. Вводим команду `git config --global user.email "<your_email@example.com>"`, где вместо `<your_email@example.com>` пишем электронную почту, на которую зарегистрирован профиль GitHub.

### Создание SSH-ключа для подключения к удалённому репозиторию

Для того, чтобы мы могли что-то выгружать и не подтверждать каждый раз что-то через ввод пароля, создадим ключ для SHH-подключения:

1. В том же Git Bash вводим команду `ssh-keygen -t ed25519 -C <your_email@example.com>">`, где вместо `<your_email@example.com>` пишем электронную почту, на которую зарегистрирован профиль GitHub, а потом на все предложения ничего не вводим и просто жмём "Enter".
2. Вводим команду `cat ~/.ssh/id_ed25519.pub` и копируем то, что она вывела.
3. Далее переходим по [ссылке](https://github.com/settings/keys) и жмём зелёную кнопку "New SSH key", где пишем название нашего ключа в поле "Title", например, "MY LAPTOP", а в поле "Key" вставляем то, что мы скопировали с предыдущего шага, и нажимаем "Add SSH key".
4. Потом заходим в VS Code, где в терминал вводим `ssh -T git@github.com`, если вывелось "*hi Karina...*", где вместо "Karina" твой ник на GitHub, то значит, теперь можно спокойно создавать репозиторий.

## Создание репозитория

1. Переходим в VS Code в папку, где лежат лабораторные работы, через "Open Folder".
2. Вводим в терминал команду `git init`, так у нас инициализируется репозиторий на самом ПК.
3. Затем переходим на GitHub во [вкладку создания репозитория](https://github.com/new), где вводим "Repository name", например, "petrsu_labs", и кликаем "Create repository".
4. Возвращаемся в VS Code и вводим в терминал `git add .`
5. Далее фиксируем наши изменения с помощью команды в терминале `git commit -m "Первый коммит"`
6. Вновь возвращаемся на GitHub и копируем ссылку на наш репозиторий для лаб. Она в этом окошке будет:
   ![Скриншот](images/github_screen.png)
7. Потом в терминале VS Code прописываем `git remote add origin <ссылка_которую_скопировали_с_гитхаба>`, наш репозиторий на компьютере теперь связан с удалённым.
8. Выгружаем всё в него командой в терминале `git push -u origin main`.

ВСЁ! Теперь твои лабораторные работы лежат на GitHub и их можно выгружать на любое устройство.
